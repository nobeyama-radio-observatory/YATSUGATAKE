# 0007. MTS を使わず、1PPS を ADC に入れない（時刻の要求 100 µs）

- 状態: 採用
- 決定日: 2026-09-17（MTS）・2026-09-18（1PPS の構成と時刻の要求）
- 根拠: study-rfsoc proj006・proj007・proj008

## 背景

4 つの ADC はタイル 224 と 226 の 2 つに分かれる。タイル間のサンプルのずれをどう扱うか、また時刻の較正のために 1PPS を ADC の入力に常時入れるかを決める必要があった。

## 決定

- **MTS（Multi-Tile Synchronization）は使わない**
- **1PPS を ADC に常時入れない。** ADC の 4 入力はすべて科学信号に使う
- **分光計に要求する時刻の精度は 100 µs**（最速の 1 kHz の記録の 1/10）

## 理由

- 自己相関の分光ではタイル間・ボード間のサンプル位相のコヒーレンスは要らない
- 実測で、**タイル内のずれは 0.02 サンプル以内で起動ごとに変わらず、タイル間は固定の 180°（ボードの極性反転）＋ 1〜1.5 サンプル RMS**。ゆらぎは RFDC の内部 FIFO 由来（8 サンプルの倍数）ではなかった
- MTS の参照デザインは LMK / LMX を別の周波数系に張り替える構成で、fs と外部基準の系統がまるごと変わる。その構成で PLL がロックしない報告もあり、PL 側の SYSREF のピンも確認できなかった
- 時刻の誤差の要素（ADC までの遅れ 213 ns・Overlay ごとの 6.5 ns・タイル間 1.9 ns）は**要求の 100 µs より 4〜5 桁小さい**。1PPS で較正する必要が無い

## 見送った案

- **1PPS を ADC の 1 ch に常時入れてエポックごとの較正器にする**（proj007 の帰結として一度検討）: 較正が要らないことを proj008 で確かめた。科学 ch を 1 本失う
- **MTS**: 上の理由で、得るもの（自己相関では不要）に対して失うもの（fs と外部基準の系統）が大きい

## 影響

- 相互相関・合成・位相を使う処理をする場合は、タイル間の 180° の極性反転を揃える必要がある（自己相関では見えない）
- 1PPS は「サンプル位相を揃える信号」ではなく、時刻の原点・ホールドオーバ・破綻の検出に使う（[0008](0008-time-labels-beat-counter-and-start-at.md)）
