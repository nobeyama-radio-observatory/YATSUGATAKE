# 0012. 窓の分光に PFB（T = 4、sinc × Kaiser β 5・bw 1.198）

- 状態: 採用
- 決定日: 2026-10-07
- 根拠: study-rfsoc proj020

## 背景

窓の分光は DDC の出口 z を矩形の窓で 4096 点 FFT しており、ch の応答のサイドローブが −13 dB と高く、ch の間に谷（半 ch で −3.92 dB）があった。

## 決定

- **DDC の出口と複素 4096 点 FFT の間に、4 タップの多相の重み付き和（PFB、T = 4）を入れる**
- 原型は **sinc × Kaiser β 5、bw 1.198**、16384 タップ、係数 18 bit
- **係数は Σh² = 4096 で規格化する**（雑音の電力を保つ）
- 置き場所は窓の分光の溜め。溜めを 5 面のリング（URAM）にし、IP へ流す 4096 語を 4 面から読んで積和する

## 理由

- 実機で、半 ch −3.00 dB・−3 dB 幅 1.000 ch が 6 つの幅すべてで模型どおり。**隣の ch と −3 dB で交わり、ch の間に谷が無い**
- 雑音の電力を保つ規格化なら、強度の単位（[0015](0015-intensity-unit-and-lmx-power.md)）と「窓の和 = TP」がそのまま使える。実機で全帯域の和 / TP は 0.9068（矩形の proj017 で 0.9076）と変わらず、ch の中心の利得は 0.995（W-6 −0.046 dB、予言 −0.043 dB）
- 溜めと履歴を兼ねられ、積和が IP の前の途切れない流れに乗る。URAM には空きがあった

## 見送った案

- **β 8・bw 1.00（最初の決定）**: 臨界サンプリングの PFB では ch の間に谷（半 ch −5.9 dB）ができる
- **ch の中心の CW の振幅を保つ規格化**: 雑音の値が変わり、単位の式に係数が入る
- **z の入口に別の遅延線を置く／BRAM に履歴を置く**: 溜めと別に記憶が要る

## 影響

- ダンプの重心は矩形より 1.5·L(NS) 前にずれる。v2 では specd が utc_ns から引く（[0016](0016-interface-v2.md)）
- 遠いサイドローブは浅くなる（≧ 1.5 ch で −58 dB）。≧ 1 ch のサイドローブ（模型 −54〜−58 dB）は試験音の裾の下で、実機では確かめられていない
- `-1` は実装の戦略 Performance_Explore で +0.047 ns。壁は PFB ではなく既存の配線の押し出し
