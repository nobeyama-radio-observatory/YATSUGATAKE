# 0005. fs 4096 MSPS・第 2 ナイキストで IF 2〜4 GHz を間引かずに PL へ

- 状態: 採用
- 決定日: 2026-09-18
- 根拠: study-rfsoc proj009（最終仕様・結論）

## 背景

45m から来る IF は 2〜4 GHz で、4 入力ある。1 本の IF から複数の窓（目標 4、最高 8 など）を切り出したい。

## 決定

- **IF 2〜4 GHz をアナログで下げずに、fs = 4096.0 MSPS の第 2 ナイキストゾーンで直接サンプリングする**（RFDC の `NyquistZone = 2`）
- タイル PLL は R = 1 / N = 25 / M = 3（VCO 12288 MHz）。LMX の 491.52 MHz をそのまま使う
- **RFDC のハード DDC は使わず、全レートを PL に入れ、PL の中で分配する**
- RFDC は 1 語 16 サンプルを出せない（有効値 7〜12）ので、**12 サンプル / 341.33 MHz で受け、入口のギアボックスで 16 サンプル / 256 MHz に詰め替える**。以降の DSP は 256 MHz・16 並列

## 理由

- ハード DDC は ADC 1 本につき 1 系統しかなく、1 本の IF から複数の窓を取れない
- 2 GHz 幅を実数サンプリングで 1 つのゾーンに収めるには fs = 4.0 GSPS ちょうどが要り、どの fs でも帯域の端は 100 MHz 前後削れる。作れる候補のうち 4096.0 MSPS は R = 1 で外部 10 MHz の系統を変えずに済み、上側に 96 MHz の余裕がある。**1 秒 = 256,000,000 ビートちょうど**になる
- 使える帯域は 2.10〜4.00 GHz

## 見送った案

- **3932.16 MSPS**: 下端 2.0 GHz から使えるが、3.86 GHz より上を失う
- **4.000 GSPS ちょうど**: 491.52 MHz から作れず、LMX を分数分周にするとスプリアスを抱える
- **4915.2 MSPS**: 2〜4 GHz がゾーン 1 と 2 にまたがり、帯域が重なる

## 影響

- **ゾーン 2 はスペクトルが反転する**（IF = 4096 − f_obs MHz）。周波数軸の向きに注意
- 2.0〜2.05 GHz の成分が 2.05〜2.10 GHz に折り返す。**ADC の前の BPF は下端を急峻に切る必要がある**
- 8 並列インタリーブのイメージ（f ± k·fs/8）が較正の収束後で −53〜−66 dBc 立ちうる。Overlay を読んだ直後（数秒）は悪い
