# 0020. ドキュメントは日本語で書き、英語版は後で足す

- 状態: 採用
- 決定日: 2026-10-08

## 決定

- 開発中のドキュメント（仕様・ADR・知見・設計・性能評価）は**日本語**で書く
- **英語版は後で足す。** 最初に英語にするのは、外部の利用者が最初に読むもの（README・使い方・仕様）
- README には英語の短い説明を併記する

## 理由

- 開発は日本語で進めている。試行の記録（study-rfsoc）も日本語で、要約の正確さを優先する
- コミュニティに公開するので、最終的には英語版が要る

## 影響

- 英語版を足すときは、日本語版と同じ場所に `*.en.md` を置く案（決めるのは英語版に着手するとき）
