# 0009. 時刻の格子 2.048 ms・dt 40.96 / 10.24 ms・TP 1.024 ms

- 状態: 採用
- 決定日: 2026-10-02（2026-10-08 に START_AT の規則を v2 で補足）
- 根拠: study-rfsoc BITS.md（時刻の格子と dt）・proj017・INTERFACE.md の 5.1

## 背景

同じ観測で幅の違う窓（256〜8 MHz）を同時に取る。窓のフレームの長さ L = 16·2^(NS−1) µs は幅ごとに違う。最初に決めた dt 40 ms は、NS ≧ 5 の L（128・256・512 µs）で割り切れなかった。

## 決定

- **時刻の格子 G = 524,288 ビート（2.048 ms）。** WRST・RUN・TP_ARM の START_AT は G の倍数に置く。窓の分光は最初のフレーム（F0）を格子に寄せる
- **dt は SAM45-Wide・SAM45-Fine・Fine が 40.96 ms、ほかの 6 本が 10.24 ms**
- **total power の区切りは 1.024 ms**（512 フレーム）
- インターフェース v2 では、PL のダンプを 10.24 ms（基本の単位）にし、長い積分は specd が束ねる。specd は START_AT を T の tint の倍数に置く（[0016](0016-interface-v2.md)）
- 幅の違う窓の区切りに残る NS ごとの一定の差（NS 1 と 8 で 10 µs）は受け入れ、時刻は DUMP_T と遅れの定数で厳密に貼る

## 理由

- **全窓のダンプの区切りをサンプルの時刻で一致させるため。** 40.96 ms = 20 × 2.048 ms は NS 1..8 のすべての L で割り切れ、10.24 ms の 4 倍
- 1.024 ms の TP は 40.96 ms に 40 区切り、10.24 ms に 10 区切りで入り、分光と比べやすい
- NS ごとの差は dt に対して 2.4e-4 以下で、時刻としては正しく貼れている

## 見送った案

- **dt 40 ms・TP 1 ms**: 幅の違う窓で区切りが揃わない
- **格子を秒に揃える**: 1 秒は 2.048 ms の倍数でない
- **NS ごとの差をハードで消す**: 得るものに対して回路と sim の手間が大きい

## 影響

- Overlay をまたいだ格子の一致は求めない（T の原点が Overlay ごと）
- 外部の状態入力（ON / OFF / HOT）は分光計に入れない。アンテナの時系列とは時刻で関連付ける
