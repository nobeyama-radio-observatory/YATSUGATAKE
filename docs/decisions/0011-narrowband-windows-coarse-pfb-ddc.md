# 0011. 狭帯域の窓は粗い PFB ＋ NCO ＋ 半帯域の縦続 ＋ 複素 4096 点 FFT

- 状態: 採用
- 決定日: 2026-09-29（方式）・2026-09-30（4 ADC への展開と時分割）
- 根拠: study-rfsoc proj014・proj015

## 背景

IF 2〜4 GHz の中の任意の位置に、幅 256〜8 MHz の窓を ADC ごとに複数置きたい。入力は 256 MHz・16 並列。

## 決定

- **粗い PFB（ch の間隔 128 MHz・4 倍のオーバーサンプリング、各 ch 512 MSPS）→ 窓ごとの NCO → 半帯域の ÷2 の縦続 → 複素 4096 点 FFT**
- 粗い PFB は ADC ごとに共有し、DDC は時分割する
- 窓の出力は複素 W MSPS、最終段の半帯域の遷移は 0.45W〜0.55W（折り返しがちょうど両端 5 % に落ちる）
- **フィルタの要求**: 中央 90 % の平坦さ ≦ 0.1 dB p-p、主の経路以外（窓の外・折り返し・鏡像）≦ −60 dB、係数 18 bit
- 窓の中心周波数はハードでは帯域の中なら任意（NCO 32 bit）。PS の既定は ch の格子（W/4096 刻み）に乗せる。k·fs/8（2560・3072・3584 MHz）を含む窓は PS が警告する（禁止はしない）

## 理由

- 4 倍のオーバーサンプリングにすると、幅 256 MHz 以下の窓はどこに置いても粗い ch 1 本の平らな帯域に収まる（境目をまたがない）
- 窓ごとに 16 サンプル / クロックで直接 DDC を作るより資源が小さい。時分割なしでは 16 窓 ＋ 全帯域で ≒ 95 % になり入らなかった
- −60 dB は、既存の分光計（XFFTS）の ch の応答と同程度で、他の望遠鏡で問題が出ていない
- 実機で、模型 → 固定小数点 → RTL（bit 単位）→ 実機が同じ数字になった（平坦さ・主以外の経路・単位）

## 見送った案

- **窓ごとの直接の DDC**: 16 並列の入力のまま窓ごとにミキサとフィルタを置くと重い
- **窓の位置を W/2 の格子に固定**（NCO が要らない）: 線を窓の中央に置けない
- **8 MHz のまま FFT を 8192 / 16384 点にして 4・2 MHz を作る**: メモリと読み出しが 2〜4 倍

## 影響

- 窓の分光の ch の形は [0012](0012-window-pfb-t4.md) で PFB に置き換えた
- 広帯域（1 GHz・512 MHz）は全帯域の FFT を伸ばして ch を選ぶ方式の予定（SAM45-Wide で決める）
