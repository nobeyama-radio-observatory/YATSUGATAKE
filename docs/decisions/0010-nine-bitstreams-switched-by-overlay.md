# 0010. 9 本の bit を Overlay で切り替え、bit の中の構成はレジスタで

- 状態: 採用
- 決定日: 2026-09-29（Overlay で切り替える方針）・2026-10-02（9 本の仕様）
- 根拠: study-rfsoc proj014（最終仕様・着手の前に決めたこと）・BITS.md

## 背景

観測によって必要な帯域・分解能・窓の数が大きく違う（全帯域 2 GHz から 8 MHz の窓まで、4096〜131072 点）。1 本の .bit にすべてを入れると資源が足りない。

## 決定

- **用途ごとに .bit を分け、PYNQ の Overlay で切り替える。** bit の中の行（幅・窓の数・点数）はレジスタで切り替える
- 作る bit は次の 9 本（詳細は `docs/spec/bits.md`、移植時に作る）

| bit | ADC | 概要 |
|---|---|---|
| SAM45-Wide | 4 | 2048 / 1024 / 512 MHz・4096 点・40.96 ms |
| SAM45-Fine | 4 | 窓 2 / ADC・256〜8 MHz・4096 点・40.96 ms |
| 2G | 1 / 2 / 4 | 2048 MHz・131072〜32768 点・10.24 ms |
| 512M | 4 | 512 MHz・16384 点・10.24 ms |
| 256M | 4 | 256 MHz・65536〜4096 点・10.24 ms |
| SpW6 | 4 | 窓 6 / ADC・128〜8 MHz・8192 点・10.24 ms |
| SpW8 | 4 | 窓 8 / ADC・128〜8 MHz・4096 点・10.24 ms |
| SpW20 | 2 | 窓 20 / ADC・64〜8 MHz・4096 点・10.24 ms |
| Fine | 4 | 128〜8 MHz・16384 / 32768 点・40.96 ms |

- **どの bit にも共通で入れるもの**: ADC ごとの total power（1.024 ms）・時刻の格子に乗った開始・時刻ラベル・設定番号・健全性の語・`-1` で閉じること

## 理由

- 窓のモードは 1 観測（≒ 1 時間）のあいだ変えない運用で、観測の開始時に数秒のリードタイムは許される。だから Overlay の切り替え（≒ 10〜20 s）で足りる
- bit を分ければ、それぞれの bit が FPGA を使い切れる

## 見送った案

- **1 本の bit にすべてのモードを入れる**: 資源が入らない

## 影響

- bit の数が増えるほど回帰の手間が増える。共通コアを持ち、PS のソフトと受け側を 1 本にする（[0016](0016-interface-v2.md)）
- 窓の幅は 4096 MHz の 2 のべき乗分の 1。各窓の両端 5 % は遷移帯として使わない（使えるのは中央の 90 %）
