# 0015. 強度の単位（abs の式）と LMX の出力 PWR 3

- 状態: 採用
- 決定日: 2026-10-07
- 根拠: study-rfsoc proj019

## 背景

スペクトルの値を、SHIFT（FFT の段ごとの切り捨て）・窓の幅・積分の回数に依らない単位で受け側へ渡したい。また、クロックの櫛（n × 163.84 MHz）のスプリアスが見えていた。

## 決定

- **絶対強度の単位を次で定める**（14 bit の ADC の LSB²）

  abs = (Σp / N_ACC − 2/3) · 4^SHIFT · 4^(4−G) / 2³¹

  束ねたダンプでは N_ACC を束の総フレーム数に読み替える
- TP の dBm への換算は ADC ごとの係数 1 つ（較正ファイル）
- **LMX2594 の出力の強さ（OUTA・OUTB の PWR）を 31 → 3 にする**（specd の既定）

## 理由

- 実機で、SHIFT・窓の幅に依らず、窓の和 = TP（0.5 % 以内）。リニアリティ L-1 ≦ 0.04 dB・L-2 ≦ 0.02 dB
- スプリアスはクロックの櫛（LMX の 491.52 MHz の経路）と k·fs/8（インタリーブ）で、運転のレベルでは揺れず、チョッパーホイールの Ta* では消える（ヌル試験）
- PWR 3 で櫛の和が −5.7 dB 下がり、タイル PLL のロック・位相雑音・床は変わらない（PWR 0 までロックする）

## 見送った案

- **生の積分値だけを渡し、換算を受け側に任せる**: 受け側ごとに式を持つことになり、間違えやすい

## 影響

- 分光計に固有の Ta* の残りは Tsys の 2e-5 以下（ADC どうしの差）
- 狭い窓の置き場（櫛と k·fs/8 を避ける IF）の表は保留
