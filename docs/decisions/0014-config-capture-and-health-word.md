# 0014. 設定は RUN / WRST で取り込み、CFG_ID と健全性の語をダンプに貼る

- 状態: 採用
- 決定日: 2026-10-02
- 根拠: study-rfsoc proj016・INTERFACE.md の 1.

## 背景

45m に載せるには、どの設定で取ったダンプか・そのダンプの間に異常が無かったかを、ダンプ自身が言える必要がある。

## 決定

- **窓の設定（WK・WDPHI・WNS）は WRST で、N_ACC・N_DUMP・SHIFT・CFG_ID は RUN で取り込む。** RUN の間の書き込みは次の RUN まで効かない
- 各ダンプに **CFG_ID**（設定番号）を貼る
- 各ダンプに**健全性の語**（DUMP_H）を 1 語貼る: PPS の欠落・間隔・グリッチ・原点の変化・ADC の振り切れ・入力の途切れ・帳簿の食い違い
- ダンプの帳簿（SEQ・DUMP_*）は同じ commit で切り替わり、PS は seqlock（SEQ → 中身 → SEQ）で読む

## 理由

- 観測の途中で設定を変えない運用なので、ダンプの境目ではなく RUN で取り込めば足り、構造が単純になる
- 健全性はダンプ単位で出せば、受け側が捨てるダンプを機械的に決められる
- 実機で、PPS を抜く・CLK_IN を抜く・振り切れの各事象で対応する旗が立つことを確かめた（陽性対照）

## 見送った案

- **ダンプの境目で設定を入れ替える**: 運用に対して構造が重い

## 影響

- SHIFT を RUN で取り込む形は proj015 からの振る舞いの変更
- TP のレコードにも振り切れの旗（FLAGS[4]）を持つ
