# 0024. 評価のノイズソースは常時 ON、OFF の要る測りだけ道具が遠隔で切って戻す

- 状態: 採用
- 決定日: 2026-10-29
- 根拠: SAM45-Wide の H-1（YATSUGATAKE M6、2026-10-23 の `h1`・`h1n`・`h1r`）

## 背景

実験室の評価では、ノイズソースと SG を合成して ADC に入れている。ノイズソースの ON / OFF（と、SAM45-Fine の配線 S ではノイズソースを外すこと）は手作業で、遠隔で評価を続けられず、評価の律速になっていた。

ノイズを入れたままにできない測りがある。CW の応答の判定（SAM45-Wide の H-1、Fine 型の P-5・W-1）では、SG を切った P_off を引いても CW × 雑音の交差項の揺れが残る（相対の σ ≒ √(2 (N/C) / (Δν τ))）。H-1 をノイズ ON・PATT 13 で回すと揺れ 0.021〜0.041 dB で、線の 0.02 dB を越えた（`h1`・`h1r`）。ノイズ OFF・PATT 0 では 0.002〜0.011 dB（`h1n`）。PATT は SG とノイズを合成した後にあるので、PATT では C/N を変えられない。

ノイズソースの電源 KIKUSUI PMX18-2A は LAN（SCPI）で操作できる。

## 決定

- **ノイズソースはいつも ON にしておく。** ON の前提の判定は、そのまま始める
- **OFF の要る測りだけ、道具が電源の出力を遠隔で切り、終わりに必ず入れ直す**（`sw/pynq/instr.py` の `NoiseSource`・`noise_off`。宛先は環境変数 `RFSOC_NS`）
  - 例外・`sys.exit` で抜けても、プロセスの終わり（atexit）でも入れ直す。入れ直せなかったら ERROR をログに出す
  - ON にしたら出力と電流を読み返す（電流が流れていなければ止まる。ノイズソースがつながっていないことの陽性対照）
  - 電圧・電流の上限（と OVP）は前面パネルで決めておき、道具は変えない
- 道具の引数: `wideresp.py`（H-1）・`s45resp.py`（P-5）・`window.py`（W-1）に `--ns-off`。`wideresp.py` の `--patt` は H-1 の PATT 0 dB も遠隔で作る。`s45lin.py --zero` は `RFSOC_NS` があればパワーメーターの零点を遠隔で取る
- SAM45-Fine の配線 S（ノイズソースを外す）は使わない。次に P-5・W-1 を回すときに、配線 NS ＋ `--ns-off` の前提（ADC でのレベル）を測る前に書き直す

## 理由

- 合格の線と前提（ノイズ OFF）を変えずに遠隔にできる。過去の結果（`h1b`・`h1n`）とそのまま比べられる
- ノイズを入れたまま通す案（SG を上げて C/N を稼ぐ・積分を長くする）は、判定の前提と線の見直しが要り、ENBW（|u| ≦ 5）の裾の扱いも変わる
- 既定を ON にするのは、ON の前提の判定のほうが多いから。OFF にしてすぐ測り始めてよい（電源を切った後のノイズソースは周囲温度の 50 Ω と同じ）

## 見送った案

- **ノイズ ON のまま SG を上げる・積分を長くする**: 上の理由
- **ノイズの枝にプログラムアッテネータか RF スイッチを足す**: 電源が LAN で操作できるので、機材を足さずに済む
- **既定を OFF にする（SG と同じ）**: ON の前提の判定の前に毎回入れることになる

## 影響

- ON にした直後の漂い（ノイズソースが温まるまで）は測っていない。OFF の測りのすぐ後に TP の安定が要る判定（P-8・PS-3 など）を続けて回すなら、先に一度、ON にした後の TP を時間に沿って測って待ち時間を決める
- 見直す条件: ノイズソースや電源を替えたとき
