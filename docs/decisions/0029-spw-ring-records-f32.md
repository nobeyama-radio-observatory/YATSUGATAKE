# 0029. SpW のリングのレコードは PL で丸めた float32（type 5・fmt 1）

- 状態: 採用
- 決定日: 2026-10-28（開発者、study-rfsoc proj032 の D-3「決めた」）。正典に入れたのは 2026-11-04（SpW8 の移植の M5b の前）
- 根拠: study-rfsoc proj032（K-1・D-3・K-2・P-13）・[`migration-spw8.md`](../migration-spw8.md)

## 背景

interface 4.4・4.5 は「**リングの中は常に u64 の生の積分値（fmt 0）。PL は切らない・丸めない**」と決めている（2026-10-08）。
SpW8（BIT_KIND 7）の RTL は、窓のダンプを **PL で float32 に丸めてから**リングに書く（`hw/bits/spw8/src/spw/f32cv.v`・`dsink.v`）。
レコードの頭は type 5（SpW の窓）・fmt 1（f32）で、中身は 4096 × f32（16 KiB）。この形は proj032 で 2026-10-28 に決めたが、正典の 4.4・4.5 に入っていなかった（ADR 0028 の範囲の外）。

- 全窓のダンプの区切りが同じ格子にそろうので、1 ADC の 3 機関が閉じたダンプを同じ枠に流す。u64 のままだと受け手の溜めの山は 1 ADC 200〜300 KiB で、BRAM にも残りの URAM にも入らない（K-1）
- PL から PS の DDR への口 1 本の上限は 4.1 GB/s で、u64 の山 6.1 GB/s / ADC は PS が静かでも越える（D-3）。f32 なら機関ごとに URAM 1 つ（ADC ごとに 96 KiB）で受けられる
- 積分器の値（< 2^53）を f32 に最近接・偶数で丸めると、PS の今の丸め（u64 → double → float、`s45proto.f32_round`）と bit 単位で同じ値になる（< 2^53 は double が厳密）。sim の `check_ring.py` が乱数 20,000 個と端の値で照らした（`tb_f32cv`・`tb_wsb`）

## 決定

- **SpW の bit のリングのレコードは type 5（SpW の窓）・fmt 1（f32、PL が丸めた値）**。頭の欄は 4.4 と同じ（core = ADC・s = 流れの番号・SEQ はコアごと・DUMP_K は窓ごと）。中身は FFT の ch の順の 4096 × f32
- 4.5 の「リングの中は常に u64」は **SpW の bit を除く**。ネットワークの形（いつも float32）は変わらない
- **束ね**（5.1 の 5）: SpW の bit では、PS は f32 の値を double の器に足し、送るときに float32 に 1 回だけ丸める（double の器の足し込みの誤差は相対で ≦ n_sum·2^−53）。DUMP_SAT は和、FLAGS・DUMP_H は OR（ほかの bit と同じ）
- **照合**（4.5 の「u64 と f32 の両方で送る試験」）: SpW の bit にはリングに u64 が無いので、`fmt=u64`・`both` は SET で断る。PL の丸めが PS の丸めと同じことの照合は sim（`check_ring.py`）が受け持つ

## 理由

- 受け手の溜めと PS の DDR への口の速さが、u64 では足りない（K-1・D-3 の実測）。f32 にすれば溜めは 1/4 以下で、PS の u64 → f32 の変換も要らなくなる
- 丸めの値が PS の丸めと同じなので、ネットワークに出る値は u64 で束ねてから丸めるのとほぼ同じ（違いは束ねの前に 1 本ずつ丸めることだけ。値は負でないので、和の相対の誤差も ≦ 2^−24 ≒ 6e-8 で、ラジオメータの雑音より 3 桁以上小さい）

## 見送った案

- u64 のまま（4.5 のまま）: 受け手の溜めが入らず、口の速さも足りない
- 束ねも f32 で足す: 足すたびに丸めが重なる（double の器なら丸めは送るときの 1 回）

## 影響

- interface 4.4（type 5・fmt 1）・4.5（SpW の例外）・5.1 の 5（SpW の束ね）を直す
- specd の SpW Backend（移植の M5b）は type 5 のレコードを読み、double の器で束ねる。C の読み手は `s45fast` に f32 の器への足し込みを足す（proj032 の `spwfast.c` と同じ形）
