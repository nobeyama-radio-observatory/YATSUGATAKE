# 測定の規約

**測ったことと、何を測ったかは別。** 構成（信号源の型番・減衰器・分配器・フィルタ・ケーブル長）を毎回残す。

## 試験音源

- **分光計の評価に方形波源を使わない。** 高調波が −9 dBc で ADC の歪みが埋もれ、広帯域の雑音が床を 1〜2 dB 持ち上げた（proj005）
- 信号源の仕様範囲を確かめる（範囲外では波形・レベル・雑音が保証されない）
- **SFDR は信号源の高調波より良くは測れない。** フィルタ（BPF / LPF）を入れてから測る

## レベルの記録

- **SG の出力設定ではなく、ADC の入力に換算したレベルを記録する。** 途中の減衰器・分配器の損失を含める
- 経路の減衰を記録していなかったために、ある試行の絶対レベルが 54 dB 合わず、記録から再構成できなくなった（proj003 → proj005）

## 入力

- **ADC の前に 2〜4 GHz の BPF を入れる。** 下端は急峻に（2.0〜2.05 GHz が 2.05〜2.10 GHz に折り返す）
- 前の試験の設定（SG の周波数・レベル、specd の SET）が残っていないかを、始める前に STATUS で確かめる。残っていて窓が飽和した・積分時間が違った例がある（proj020・proj019）

## 混信

- 800 MHz 帯の混信は 1PPS のケーブルから入る（[`pitfalls.md`](pitfalls.md)）。携帯電話の通話で入口を比べられる
- 昼と夜、平日と休日で混信の量が変わる。長い記録は時刻と一緒に見る

## 安定度

- アラン分散は熱雑音（ノイズソース）を入れて測り、理想（ラジオメータの式）との比で読む
- ノイズソースの出力がガウスでないことがある（尖度で確かめる）。TP の比には効くが分光には効かない（proj019）
