# 2G-1-Fast v1.0.0 — 性能評価

- 状態: **M6 の判定まで**（2026-10-31）。判定したのは M5 の .bit（commit 2415023 の作り直し、FDRI は移植元・M3 と同じ）。リリース（M7）で配る .bit はタグの commit で作り直し、FDRI が判定した .bit と同じことを確かめてから、この文書の「対象」に書き足す
- 測った期間: 2026-10-31（YATSUGATAKE の 2G-1-Fast の移植の M4〜M6。経緯と生の数字は [`../../migration-2g-1-fast.md`](../../migration-2g-1-fast.md) の「M4 の結果」「M5 の結果」「M6 の結果」）

**まとめ**: 判定 7 つがすべて通過。30 分・2 時間の運転で取りこぼし 0、VCCINT 13.3〜13.8 A で平ら（2G-4 の 4 割）。1 周の計 7.31 ms（tint 20.48 ms の 36 %）。V2-b の陽性対照（リングを 8 s 読まない）でもボードは固まらなかった。時刻の較正はボードの較正ファイル（`tcal board`）。

## 周波数応答

- **ch → IF**（H-2）: 4 点（3000.25・2500.5 MHz が直接の側、3396.5・2597.25 MHz が 2-for-1 の共役の側）とも、ピークの送る番号が 60943・28959・86303・35151 で期待と一致、軸と SG の差 0.0 Hz。直接の側と共役の側で利得が同じ（ピーク / 中央値 − TP の幅 0.09 dB。移植元 proj033 R-6 の 110.9〜111.1 dB と +0.1〜+0.3 dB）
- ch の形（半 ch・−3 dB 幅）は M6 では測っていない（模型との照合は sim、M2 で移植元と同じ出力）

## 強度

M6 では線形性・TP の dBm の照合を測っていない（2G-1-Fast の判定の一覧に無い）。H-0 の TP は −31.45 dBFS で移植元 proj033 R-1 と −0.16 dB。

## 安定度

M6 では測っていない。

## スプリアス

M6 では測っていない。

## 時刻

- 物差しは DSP のクロックの数 T（256 MHz）。ダンプ 10.24 ms を束ねて tint（20.48 ms = 2 本）
- **較正**: ボードの `time_cal.json`（2G-1-Fast は (11, 1) で、ADC → コアの道は共通。`rfdc_params.rpt` が Wide の作り直しと同じ）
- 30 分・2 時間の運転で miss 0・time_ok 1

## 既知の制限

1. **`-1` の WNS +0.025 ns**（Performance_Explore）。既定の戦略では閉じない（−0.242 ns）。RTL を少し変えると負に戻る前提で扱う。直すなら proj033 の B-2（記憶のカスケードに段を足す）を study-rfsoc の新しい proj で
2. ネットワークの tint の最小は 20.48 ms（予算 30 MB/s。10.24 ms は SET で断る。試験は `--net-budget-mbs 0`）
3. `s2_sep`・`s2_q`・`s2_chain` は 2G-4 の同じ名前のファイルと中身が違う。一本化は 2G-2 の移植の後
4. 線形性・TP の dBm・安定度・スプリアス・ch の形は M6 では測っていない
