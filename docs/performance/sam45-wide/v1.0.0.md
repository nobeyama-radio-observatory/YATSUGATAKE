# SAM45-Wide v1.0.0 — 性能評価

- 状態: **v1.0.0 の性能評価**（タグ `sam45-wide/v1.0.0`・リポジトリ全体 `v1.1.0`。判定したのは M5 の .bit。配る .bit はタグの commit で作り直したもので、FDRI が判定した .bit と同じことを確かめてから配る。配る .bit の sha256・USR_ACCESS はリリースの後に足す。[`../../release.md`](../../release.md)）
- 測った期間: 2026-10-23〜10-26（YATSUGATAKE の Wide の移植の M6。経緯と生の数字は [`../../migration-sam45-wide.md`](../../migration-sam45-wide.md) の「M6 の結果」）
- 判定の手順と合格の条件: [`../../../test/acceptance/sam45-wide/`](../../../test/acceptance/sam45-wide/README.md)

**まとめ**: 14 判定のうち 12 が通過、**H-1 と F-2 は保留**（記録の判定は失敗のまま。実験者の判断で、実用上は問題ないとした。制限 1・2）。
ch ごとの安定度は最短の τ で予言の 1.00〜1.13 倍（B 1・2・4）、30 分・1 時間の運転で取りこぼし 0。
TP の dBm は Fine の較正（K）を (1, 1) にも使う（P-8 で Fine と 0.04〜0.06 dB）。時刻の較正は proj023 の値のまま（F-2 は ±2.5 ns の内）。

## 周波数応答

- **ch の形**（H-1、`h1n`）: 半 ch は B 1 −2.996〜−3.005 dB、B 2 −3.002・−3.018、B 4 −2.991・−3.031 dB（模型 −3.001・−3.010）。−3 dB 幅・ENBW（|u| ≦ 5）は 4 本とも模型 ±0.005 ch・±0.5 % の内。proj023 の h1b と ±0.003 dB
- **半 ch の両側の非対称**: B 1 0.009・B 2 0.016・B 4 0.040 dB。両側の差は u に比例し、周波数に直すと 4 本とも −0.06〜−0.08 dB/MHz（IF 3000 MHz 付近）で B に依らない。束ねる前の入力のスペクトルの傾きと合う（測った後の解析、未検証）
- **ch → IF**（H-2）: (S0 + i + (B − 1)/(2B))·fs / N の式どおり、ずれ +0.000 ch

## 強度

- **線形性**（P-8 L-1）: TP −18〜−28 dBFS で TP 4 本・流れ 8 本ともパワーメーターに比例、残差最大 0.014 dB。L-2（流れ / TP のレベル依存）≦ 0.0018 dB
- **TP の dBm**: `tp_cal.json` の K（Fine の (2, 3) と同じ、2026-10-06 に ADC の口で測った値）を (1, 1) にも使う。根拠は同じ日・同じ配線で dBFS − PM が Fine と 0.04〜0.06 dB（4 本とも Wide が同じ向きに低い。測りの間 11 分の漂いと区別できない）。STATUS に `tp_dbm` が出ることを確かめた

## 時刻

- 物差しは DSP のクロックの数 T（256 MHz）。束ねの区切りは 7 本とも r = 2·G で Overlay をまたいで一定（V2-f）、30 分・1 時間の運転で miss 0
- **較正（形 (b)、proj023 の F-2、2026-10-21）**: `pps_det_ns = 71.5`（LPF の分）・`adc_to_core_ns = 143.0・142.9・141.5・141.4`（ADC_A〜D）・`bound_ns = 5`
- M6 の F-2（PWR 3）の M は今の CAL の −1.7〜−0.1 ns。Overlay ごとの 4 ADC 共通のずれ（今回 +1.18 ビート ≒ 4.6 ns）の幅と同じ程度なので入れ直さなかった（制限 2）

## 既知の制限

1. **H-1 は保留**（記録の判定は失敗）。C0（B 4）の半 ch の下側 −3.031 dB で線 −3.030 dB の 0.001 dB 外。proj023 の h1b（−3.028、通過）を ±0.003 dB で再現していて、差は繰り返しの揺れより小さい。非対称は入力のスペクトルの傾き（≒ −0.07 dB/MHz）と合うが確かめていない（確かめ方は migration の塊 NS）
2. **F-2 は保留**（記録の判定は失敗）。2 回目（ケーブルの入れ替え）で 4 ADC がそろって +1.04〜+1.27 ビート動き、「2 回の差 ≦ 1」を越えた。ケーブルの差ではなく Overlay ごとの共通のずれ（proj021・026 の ≒ 0.9 ビートの件。原因は確かめていない）。時刻の CAL は proj023 の値のまま。40.96 ms の積分の時刻の用途には効かない
3. **H-2 の B 4 の CW の高さに余裕が無い**（CW / 中央値 10.3 dB、線 10 dB）。proj023 より 3〜7 dB 低い（10-21 に分配器を替えた後の値。原因は確かめていない）。測りの条件の制限で、ch → IF の結果（ずれ +0.000 ch）には効いていない
4. **H-1 は雑音の入った配線では測れない**。CW × 雑音の交差項で中心の揺れが ≒ 0.03 dB になる（ノイズソース OFF・PATT 0 で測る）
5. **TP の小さな跳ね**（入力の側の型、V2-b の 30 分で 285 回、0.01〜0.04 dB）。日と時間帯で出方が変わる。PS-3 の判定は step_db で数えるので効かない
6. `-1` の WNS +0.000716 ns（Performance_Explore で閉じた。作り直して閉じる保証は無い。同じ RTL の作り直しは FDRI まで同じだった）。ビルドの途中で Vivado が segfault することがある（回し直しで完走）
7. **線形性の高い側（−10〜−18 dBFS）は M6 では測っていない**
8. 受け側を閉じてから specd を STOP すると、溜まった分が次の受け側に送られる（A の記録の頭に PS-3 の終わり ≒ 204 ダンプ）。運転の手順: 受けを閉じる前に STOP する
9. `s45spur.py rec` は Wide の周波数の軸を読まない（Wide のスプリアスは `widecomb.py`）
