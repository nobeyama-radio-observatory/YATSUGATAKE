- 状態: **v1.0.0 の性能評価**（タグ `spw8/v1.0.0`・リポジトリ全体 `v1.5.0`。判定したのは M5c の .bit、commit 6ed5843。FDRI は移植元・M3 と同じ。配る .bit はタグの commit で作り直し、FDRI が判定した .bit と同じことを確かめてから配る。[`../../release.md`](../../release.md)）

## 測定系

2G-4 v1.0.0 と同じ実験室の配線（[`../2g-4/v1.0.0.md`](../2g-4/v1.0.0.md) の「測定系」）。配線は M6 の間で切り替えず N（ノイズ ON・ATT 13 dB）。W-1 だけ SG（E8257D、+9 dBm・基準 EXT）を出し、終わった後に前の状態（2000.3 MHz・+9 dBm・出力 OFF）に戻した。回しの前後に ATT 13 dB・ノイズ ON（15.00 V・511 mA）・SG を読んで同じだった。2026-11-05 に開発者が作業場で、配線がこの形であること（ADC_A を含め、つなぎの緩みは無い）・ボードのファンが正常に回っていること・4 ADC に共通する電源とアース（ノイズ源の電源・ATT・分配器・ボードの電源）に見える異常が無いことを目で確かめた。

## 周波数応答

- **ch → IF**（W-1）: 3 点（3891.125・3294.8125・2654.8125 MHz）で、CW を含む 32 か所すべてで最大の ch が予言とずれ 0
- **双子の窓**（TW）: 同じ IF を受ける 2 窓の比の揺れ 0.0016・形の相関 0.99998〜0.99999
- ch の形（半 ch・−3 dB 幅・サイドローブ）は M6 では測っていない（模型との照合は sim、M2 で移植元と出力がバイト単位で同じ）

## 強度

M6 では線形性・TP の dBm の照合を測っていない（SpW8 の判定の一覧に無い）。H-0 の TP は −31.56〜−31.73 dBFS（配線 N・ノイズ ON）。窓の中の平らさは 0.975〜1.021（H-0、D7 の例）。

## 安定度

M6 では測っていない。

## スプリアス

M6 では測っていない。

## 時刻

- 物差しは DSP のクロックの数（256 MHz）。ダンプ 10.24 ms を束ねて tint（20.48 ms = 2 本）
- **窓ごとの遅れ**: NS ごとの D(NS)（`timebase.WIN_DELAY[(7, 10)]` = 86.03・135.07・231.05・411.01・757.03 ビート）と 1.5·L(NS) を utc_ns から引く。補正の後、同じ ADC の窓（NS 1〜5）どうしで e の差 −0.1〜+0.6 ns（PS-1）。D を外すと窓どうしで 2.6 µs ずれる
- **較正**: ボードの `time_cal.json`（tcal board）
- 30 分・2 時間の運転で miss 0・time_ok 1・tdev 0

## 既知の制限

1. **`-1` の WNS +0.016 ns**（PEPRPO でだけ閉じる。既定の戦略では負）。RTL を少し変えると負に戻る前提で扱う
2. **VCCINT 39.4 A（線 40 A）・temp20 は均して 67〜68 ℃（線 70 ℃）で、余裕が小さい**。10 s ごとの生の読みは ±2 ℃ 揺れ、1 回目の V2-L では 70.11 ℃ が 2 回あった。「±1 ℃」の平らさは均した値（5 分平均）で読んでいる。proj032 P-13（62 ℃）より ≒ 6 ℃ 高く、ファンは正常に回っていた（2026-11-05 に目で確かめた）。部屋の温度の違いかどうかは確かめていない
3. ネットワークの tint の最小は、32 窓で 20.48 ms（予算 30 MB/s。10.24 ms は SET で断る。16 窓なら 10.24 ms）
4. specd を起こした直後の 1 分に、tint を越える周（≒ 48 ms）が 1〜2 回出る。原因は確かめていない（取りこぼしはリングが吸って 0）
5. 1 回目の RING の 1 回で、0.3 s の止まりに原因の分からない ≒ 0.5 s の止まりが重なり pl_drop が出た。束の記録を C に移した後の 3 回では出ていない
6. TP_JUMP が 4 ADC とも ≒ 19.5 回 / s 出る（4 ADC 共通の −0.05〜−0.17 dB・2〜8 ms のくぼみ、≒ 35 Hz）。判定の外。配線・共通の電源とアースに見える異常は無かった（2026-11-05）。原因は調べていない
7. PS-1 の float32 の写し取りは Python の道（`--fast` なし）で測った。C が出口の溜まりへ直に書く道が同じバイトを出すことは `sw/pynq/test_spw_ring.py` の 6 で確かめている
8. 線形性・TP の dBm・安定度・スプリアス・ch の形は M6 では測っていない
