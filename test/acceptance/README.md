# test/acceptance — 判定（受け入れ試験）

bit をリリースする前に実機で通す判定を、1 つずつファイルにして置く。
**判定の ID は study-rfsoc で使ったもの（F-1・W-0・V2-a など）をそのまま使う。**

## 書き方

判定 1 つにつき、次の 6 項目を書く。**環境に依る値（ホスト名・IP アドレス・パス）は書かない。**

| 項目 | 中身 |
|---|---|
| ID | F-1・W-0・V2-a など |
| 前提 | 載せる .bit（ID・版）・接続（信号源・減衰器・分配器・ケーブル）・specd の設定 |
| 手順 | 実行するコマンド（道具と引数） |
| 合格 | 数値の条件。**測る前に書く** |
| 陽性対照 | 見張りが壊れていないことの確かめ（あれば）。立ったことのないフラグは「異常が無い」と「見張りが壊れている」を区別しない |
| 記録 | 結果のファイルと、性能評価（`docs/performance/`）の該当の行 |

## ひな形

```markdown
# <ID> — <何を確かめるか>

- 前提:
- 手順:
- 合格:
- 陽性対照:
- 記録:
```
