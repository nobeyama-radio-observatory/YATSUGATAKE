# P-8 — 線形性（L-1・L-2）と窓の和 / TP

- **前提**: 共通の前提。specd（ボードで `python3 specd.py --clkin 0 --ref 10 --bits bits.json`、制御 PC から）。**配線 N ＋ パワーメーター（分配器 A の −20 dB の口）・プログラムアッテネータ**。8 窓を 256 MHz で 2048〜4096 MHz に敷き詰める
- **手順**:

```bash
python3 specctl.py --host $B "SET tint=0.04096 all.shift=9 A0.if=2176 A1.if=2432 B0.if=2688 B1.if=2944 C0.if=3200 C1.if=3456 D0.if=3712 D1.if=3968 A0.bw=256 A1.bw=256 B0.bw=256 B1.bw=256 C0.bw=256 C1.bw=256 D0.bw=256 D1.bw=256"
python3 s45lin.py --host $B --pm $PM --att $ATT --lo 6 --hi 40 --step 2 --out lin_xxx     # 2026-10-21 からは --lo 0（下の「改め」）
python3 s45lin.py --analyze lin_xxx.lin.jsonl
# 比べ: 同じ配線で proj020 の bit（specctl LOAD bit=proj020、同じ SET）で同じ測り → lin_xxx_p20
```

- **合格**（測る前に決めた条件）:
  - **窓の和 / TP（中央 90 %）が、同じ配線で測った proj020 の bit の値と ±0.5 %**（値そのものは配線のスペクトルの形で決まる）
  - L-1: PATT 10〜20 dB で TP 4 本・8 窓とも、床を引いた値がパワーメーターに比例（残差 最大 ≦ 0.05 dB）
  - L-2: 窓 / TP（同じ ADC）がレベルによらず一定（±0.02 dB）
  - 飽和・振り切れ 0 の段だけを使う（今の配線は PATT ≦ 4 dB で振り切れる）
- **改め（2026-10-21、測る前。M6 の L-1 の測り直しのため）**: 実験室の分配器を Mini-Circuits ZFRSC-42-S+（2 分配）・ZFRSC-4-842-S+（4 分配）に替え、ADC までの損失が ≒ 18 dB 増えた（PATT 13 dB で TP −30.9 dBFS、M6 の 10-17 は −12.5 dBFS。study-rfsoc proj024 4a）。PATT を 0 dB にしても ≒ −18 dBFS までしか上がらない。そこで:
  - **L-1 の範囲を dBFS で決め直す: TP が −18〜−28 dBFS になる段**（今の配線で PATT 0〜10 dB）。前の「PATT 10〜20 dB」は前の配線で −9.5〜−19.5 dBFS にあたる。**−10〜−18 dBFS の高い側は、この測り直しでは確かめない**。M5b の bit は FDRI が proj021 2-5 と同じで、その L-1（PATT 10〜20 dB、最大 0.012〜0.022 dB）で支える
  - 掃引は `--lo 0 --hi 40 --step 2`（前は `--lo 6`）
  - 窓の和 / TP（proj020 と ±0.5 %）と L-2（±0.02 dB）の条件は変えない（同じ配線での比べ）
  - 配線 N の今の形: ノイズソース → 2 分配器 A（SG の口は出力 OFF）→ PATT → BPF 2.1〜3.9 GHz → 2 分配器 B →（ATT 20 dB → パワーメーター）・（ATT 3 dB → 4 分配器 → ADC_A〜D）。1PPS・10 MHz の入口に LPF（proj026）
- **陽性対照**: 比べの proj020 の bit が同じ値を出すこと自体が、配線に依る分と分光計の分を分ける対照
