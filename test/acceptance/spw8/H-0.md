# H-0 — 立ち上げ（32 窓のレコード・K_F の格子・照合・平らさ）

- **前提**: 共通の前提。配線 N。窓の組 b5
- **手順**:

```bash
# M4
sudo -E $(which python3) spw_b5.py --clkin 0 --ref 10 --sec 10 --cfg b5 --ng 10 --out runs/h0
# M5b の後: b5 の組を論理の窓 A0〜A7 ×（A〜D）で SET し、tint 0.02048 で 10 s 受ける
```

- **合格**:
  - 窓のレコード（type 5）: CRC・尾、SEQ が 0 から 1 ずつ、窓ごとの DUMP_K が 1 ずつ、頭の NS・SHIFT・DUMP_N、**K_F = DUMP_T − 2^(12+NS)·DUMP_F0 が窓ごとに一定で 0 ≦ K_F < 2^(12+NS)**、本体が有限で負でない、動いている窓だけから来る
  - TP のレコード（type 2）: CRC・尾、SEQ が前 ＋ DUMP_N、個のフレームが続いている
  - 終わりの見張り: CORE_FLAGS 0・窓の FLAGS 0・DROP_CNT 0・EXT_CNT 0・ERR_STAT 0・レコードの数 = REC_CNT
  - 32 窓とも平らさ・中央値の比が揃う（16 MHz・8 MHz の窓を含む）。TP は −31〜−32 dBFS（ATT 13 dB）
- **陽性対照**: 照合の陽性対照は sim（M2 の `tb_core` の `-DCORE_POSCTL`・`-DIPQ_POSCTL`）。実機では `--fast-posctl` で窓のレコードが全部 CRC の誤りになる（RATE と同じ）
