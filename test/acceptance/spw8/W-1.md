# W-1 — SG の CW の ch（8 窓 × 4 コア）

- **前提**: 共通の前提。配線 N/S（SG E8257D、基準 EXT、＋9 dBm、ノイズ ON・ATT 13 dB を前後に読む）。窓の組 plan2
- **手順**: CW を 3 点（3891.125・3294.8125・2654.8125 MHz。どの窓でも ch の端数が 0 になる周波数）。**予言の ch を計画から測る前に書く**

```bash
# M4
sudo -E $(which python3) spw_b5.py --clkin 0 --ref 10 --win 3900:128,3890:64,3890:64,3892:16,3891:8,3300:128,3290:32,2650:128 --alt 2,1 --fast --ng 10 --sec 10 --tone 3891.125 --out runs/w1_0
# M5b の後: 同じ組を論理の窓で SET し、受けたスペクトルの最大の ch を論理の窓の番号で照らす
```

- **合格**: CW を含む窓（ピーク / 中央値 ≧ 20 dB）は全部、**最大の ch が予言の ch とずれ 0**（3891.125 MHz: 窓 0〜4 で ch 284・4024・4024・224・4032、3294.8125 MHz: 窓 5・6 で 166・3480、2654.8125 MHz: 窓 7 で 3942）。4 コアとも。M5b の後は**論理の窓の番号**で同じ ch（specd の読み替えが正しい）
- **陽性対照**: 予言の ch を 1 ずらして照らすと落ちる。P-10b の 1 回目の誤り（R0 512）が残っていれば CW は 64〜13,056 ch ずれる（見分ける力）
- **記録**: proj032 P-13b（2026-11-03、b5 rev 10、`runs/p13_cw0〜2`）: 32 か所とも ずれ 0、ピーク / 中央値 35.5〜54.7 dB、3 回とも全部通過（DROP 0・FLAGS 0）。SG は終わった後、元の状態に戻した
