# W-1 — SG の CW の ch（8 窓 × 4 コア）

- **前提**: 共通の前提。配線 N/S（SG E8257D、基準 EXT、＋9 dBm、ノイズ ON・ATT 13 dB を前後に読む）。窓の組 plan2
- **手順**: CW を 3 点（3891.125・3294.8125・2654.8125 MHz。どの窓でも ch の端数が 0 になる周波数）。**予言の ch を計画から測る前に書く**

```bash
# M4
sudo -E $(which python3) spw_b5.py --clkin 0 --ref 10 --win 3900:128,3890:64,3890:64,3892:16,3891:8,3300:128,3290:32,2650:128 --alt 2,1 --fast --ng 10 --sec 10 --tone 3891.125 --out runs/w1_0
# M5b の後（specd --spw --fast --fast-ring。既定の組が plan2）: 窓 2 を 2 番目に近い粗い ch・窓 1 を近い ch に決め打ち、CW ごとに 250 束
python3 specctl.py --host $B "SET tint=0.04096 A2.coarse=alt B2.coarse=alt C2.coarse=alt D2.coarse=alt A1.coarse=near B1.coarse=near C1.coarse=near D1.coarse=near" "CLEAR" "START n=250" "SEND ON"
python3 specrecv.py --host $B --report 0 --seconds 14 --out runs/w1_0.s45
python3 hw/bits/spw8/tools/spw_recv_check.py runs/w1_0.s45 --win 3900:128,3890:64,3890:64,3892:16,3891:8,3300:128,3290:32,2650:128 --alt 2,1 --tone 3891.125   # 陽性対照は --posctl-pred 1
```

- **合格**: CW を含む窓（ピーク / 中央値 ≧ 20 dB）は全部、**最大の ch が予言の ch とずれ 0**（3891.125 MHz: 窓 0〜4 で ch 284・4024・4024・224・4032、3294.8125 MHz: 窓 5・6 で 166・3480、2654.8125 MHz: 窓 7 で 3942）。4 コアとも。M5b の後は**論理の窓の番号**で同じ ch（specd の読み替えが正しい）
- **陽性対照**: 予言の ch を 1 ずらして照らすと落ちる。P-10b の 1 回目の誤り（R0 512）が残っていれば CW は 64〜13,056 ch ずれる（見分ける力）
- **記録**: proj032 P-13b（2026-11-03、b5 rev 10、`runs/p13_cw0〜2`）: 32 か所とも ずれ 0、ピーク / 中央値 35.5〜54.7 dB、3 回とも全部通過（DROP 0・FLAGS 0）。SG は終わった後、元の状態に戻した
- **記録（specd、M5b）**: YATSUGATAKE M5b（2026-11-04、`hw/bits/spw8/runs/m5b/w1_0〜2`）: 論理の窓の番号で 32 か所とも ずれ 0、ピーク / 中央値 34.7〜54.8 dB、受け側の照合 通過・miss 0・pl_drop 0。陽性対照（予言 ＋1）は 3 点とも落ちた。SG は元の状態に戻した
- **記録（M6）**: YATSUGATAKE M6（2026-11-04 06:54〜06:55 UTC、M5c の bit、specd、`runs/m6/w1_0〜2`）: 論理の窓の番号で 32 か所とも予言の ch とずれ 0、ピーク / 中央値 36.3〜55.3 dB、受け側の照合 通過。陽性対照（予言 ＋1）は 3 点とも落ちた。SG は使う前（2000.3 MHz・＋9 dBm・出力 OFF・基準 EXT）に戻した。**通過**
