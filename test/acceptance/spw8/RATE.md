# RATE — PL と PS の取得 10.24 ms × 32 窓で 30 分

- **前提**: 共通の前提。配線 N・SG 出力 OFF。リング 64 MiB。C の読み手（M4: `libspwfast.so` をボードで `gcc -O3 -march=armv8-a+crc` で作る。M5b の後: specd の `--fast --fast-ring`）。AMS の温度と VCCINT を 10 s ごとに記録
- **手順**:

```bash
# M4
sudo -E $(which python3) spw_b5.py --clkin 0 --ref 10 --cfg b5 --fast --ng 5 --sec 1800 --out runs/rate
# M5b の後: PL の tint 10.24 ms・ネットワークの tint 20.48 ms（specd が 2 つずつ束ねる）で 30 分。受けは V2-b と同じ
```

- **合格**: 30 分で **DROP 0・照らしの誤り 0・CORE_FLAGS 0・窓の FLAGS 0**、輪の中の時間の割合 ≦ 70 %（P-13 の 55 % に余裕を見る）、リングの PEAK が運転中に増えない、VCCINT ≦ 40 A・温度が平ら（30 分の後半で ±1 ℃）
- **陽性対照**: `--fast-posctl`（C の CRC の期待値を 1 bit 反転）で窓のレコードが全部 CRC の誤りになる。Python の読み手（`--fast` なし）では DROP が出る（P-9・P-13 の 1 行目）
- **記録**: proj032 P-13（2026-11-03、`runs/p13_long`）: 1800 s・51.6 MB/s・DROP 0・輪の中の時間 55.0 %・1 本 176 µs・PEAK 40.1 MB（30 s と同じ）・窓のレコード 5,626,480 本・照らしの誤り 0、VCCINT 38.5 A・temp20 62.2〜62.6 ℃。**全部通過**
- **記録（M6）**: YATSUGATAKE M6（2026-11-04、M5c の bit）。**試行の道具**（06:22〜06:52 UTC、`--cfg b5 --fast --ng 5 --sec 1800`、`runs/m6/rate_tool`）: 51.6 MB/s・DROP 0・照らしの誤り 0・CORE_FLAGS 0・窓の FLAGS 0・輪の中の時間 55.0 %・1 本 176 µs・PEAK 40.3 MB（P-13 と同じ）・窓のレコード 5,626,510 本。VCCINT 38.5〜39.1 A（10 s ごと、183 回）。temp20 は後半 15 分の平均 67.98 ℃・前後半 7.5 分の平均 68.04 / 67.92 ℃（傾きなし）・1 分平均の幅 1.16 ℃・5 分平均の幅 0.27 ℃・10 s ごとの読みの幅 3.36 ℃（σ 0.70 ℃）。P-13 も同じ読みの揺れ（σ 0.67 ℃、生の幅 2.7 ℃）で、記録の 62.2〜62.6 ℃ は均した値。**「±1 ℃」の均し方を測る前に決めていなかった**。P-13 と同じく均した値で読み、**通過**とする。温度は P-13 より 5.6 ℃ 高い（VCCINT はほぼ同じ。部屋かファンの違いと見るが確かめていない）。**specd**（V2-b と同じ運転、06:57〜07:28 UTC）: pl_drop 0・miss 0・CRC 0、取得の時間（`spw_c_scan_s ＋ spw_c_ev_s ＋ spw_c_one_s` = 319.65 ＋ 766.67 ＋ 165.20 s）÷ RUN 1,800.8 s = **69.5 %**（線 70 %）、pl_peak 33.9 MB は最初の 1 分で決まり後は増えない。VCCINT は中央値 39.25 A・p99 39.49 A、40 A を越えた読みは START を打った瞬間（ARMED）の 1 回 40.32 A だけ。temp20 は後半の平均 68.17 ℃・1 分平均の幅 0.92 ℃。**通過**（ただし余裕は 0.5 % と 0.5 A）
