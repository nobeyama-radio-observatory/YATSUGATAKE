# PS-1 — float32・utc_ns の補正（D(NS) の表が SpW8 の値で当たる）

- **前提**: 共通の前提。配線 N。M5a（D(NS) の表）と M5b の後。窓の組 b5（NS 1〜5 を全部含む）
- **手順**: specd で 10 s 受け、窓ごとに e = utc_ns − dump_t·125/32 ＋ (D(NS) ＋ 1.5·L(NS))·125/32 を出す（SAM45-Fine の `s45v2c.py` の形を SpW8 の窓に）
- **合格**:
  - specd の ID・STATUS の時刻の較正が `(7, 10)` の表を引いている（「未較正」でない）。SAM45-Fine の値（NS 1 で 57.56 ビート）が当たっていない
  - 同じ ADC の窓どうしで e が一致（±2 ns）。D(NS) は 86.03・135.07・231.05・411.01・757.03 ビート（NS 1〜5）
  - float32 の値が PL の記録（f32）とバイト単位で同じ
- **陽性対照**: 表から (7, 10) を外して起こすと「未較正」になり、SET か START が理由つきで止まるか、記録に未較正の印が付く（M5a の決めに従う）
- **記録**: なし（D(NS) は proj032 P-12 の sim。位相による揺れ NS 5 で最大 ±5 ビートは不確かさとして記録する）
