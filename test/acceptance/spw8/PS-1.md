# PS-1 — float32・utc_ns の補正（D(NS) の表が SpW8 の値で当たる）

- **前提**: 共通の前提。配線 N。M5a（D(NS) の表）と M5b の後。窓の組 b5（NS 1〜5 を全部含む）
- **手順**: specd で 10 s 受け、窓ごとに e = utc_ns − dump_t·125/32 ＋ (D(NS) ＋ 1.5·L(NS))·125/32 を出す（SAM45-Fine の `s45v2c.py` の形を SpW8 の窓に）
- **合格**:
  - specd の ID・STATUS の時刻の較正が `(7, 10)` の表を引いている（「未較正」でない）。SAM45-Fine の値（NS 1 で 57.56 ビート）が当たっていない
  - 同じ ADC の窓どうしで e が一致（±2 ns）。D(NS) は 86.03・135.07・231.05・411.01・757.03 ビート（NS 1〜5）
  - float32 の値が PL の記録（f32）とバイト単位で同じ
- **陽性対照**: 表から (7, 10) を外して起こすと「未較正」になり、SET か START が理由つきで止まるか、記録に未較正の印が付く（M5a の決めに従う）
- **記録**: なし（D(NS) は proj032 P-12 の sim。位相による揺れ NS 5 で最大 ±5 ビートは不確かさとして記録する）
- **記録（M6）**: YATSUGATAKE M6（2026-11-04、M5c の bit、`runs/m6/ps1_e.txt`・`tap_ab`・`tap_cd`・`nodly`）。表: `GET CAL` に `wdly=7.10`・`wdly_ns=1:86.03,…,5:757.03`（「未較正」でない）。**e**（H-0 の specd の運転、32 窓・NS 1〜5、`hw/bits/spw8/tools/spw_ps1.py check`）: 4 ADC とも窓 0 との差 −1.0〜0.0 ns（線 ±2 ns）・窓の中の e の幅 0.0 ns・束の間隔 20,480,000 ns ちょうど・記録は版 2 だけ。道具の中の陽性対照: D を足さない e の窓どうしの幅 2,621.5 ns・1.5·L を足さない 720,000.4 ns・SAM45-Fine の表 (2, 3) を当てると 1,252.2 ns。**float32**: tint 0.01024・窓 16 本（A・B と C・D の 2 回、n_sum 1）の SPEC の本体が、同じ運転で PL のリングから写し取った type 5 の本体（`spw_ps1.py patch` の包み、Python の道）を IF の昇順に並べたものと **256 本 ＋ 256 本ともバイト単位で同じ**。並べ替えずに比べる陽性対照は 512 本とも違った。写し取りの specd は Python の道で写す分が重く pl_drop 2,266・6,525 が出た（受け側の照合は通過、比べは写せた本だけ）。**陽性対照**（`spw_ps1.py patch-nodly` で (7, 10) の行を外した specd）: `GET CAL` が `wdly_ns=none`、e は NS ごとに D の差だけずれる（NS 2 ＋190.9・NS 3 ＋566.3・NS 4 ＋1,269.4・NS 5 ＋2,620.6 ns）で落ちた。SET・START は止まらない（M5a の決め）。**通過**。道具の 1 回目は utc_ns（≒ 1.8×10¹⁸）を float64 で引いて ±256 ns の刻みが出た（道具の誤り。整数で基準を引いてから計算するよう直し、同じ記録で照らし直した）
