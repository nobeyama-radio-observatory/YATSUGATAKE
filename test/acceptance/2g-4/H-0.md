# H-0 — 4 窓の立ち上げ（頭の欄・照合・床）

- **前提**: 共通の前提。配線 N か N/S（どちらかを記録に書く。床の値は配線で変わる）
- **手順**:

```bash
python3 specctl.py --host $B "SET A0.src=A B0.src=B C0.src=C D0.src=D shift=7 tint=0.04096 fmt=f32" "SEND ON" "START n=200"
python3 specrecv.py --host $B --out h0.s45 --seconds 15 --json h0.json
python3 g24cw.py h0.s45 --src ABCD
```

- **合格**:
  - 受け: 4 窓 × 200・CRC 0・説明のない欠け 0・照合 通過
  - `g24cw`: 全部通過（kind 1・nch 32768・core 0〜3・src 0〜3・nacc・df 62,500 Hz・bit_kind 3・DUMP_T の進み・4 窓で DUMP_T が揃う）
  - flags 0・health 0・miss 0
  - 床（1 フレームあたりの中央値）: 同じ配線の proj031 の値と ±0.7 dB（Overlay の載せ直しごとに 0.3〜0.6 dB 動く。proj031 R-3）
- **陽性対照**: `g24cw.py --src DCBA`（期待の src を入れ替える）で 4 窓とも NG（src の照合）。`--posctl` は CW の判定（`--sg-mhz`）にしか効かないので H-0 の陽性対照にならない（H-2 の陽性対照。M0 で書き誤り、2G-4 の M4 で「全部通過」になって気づいた）
- **記録**: proj031 R-1a rev 2（N/S・ノイズ OFF）: 4 窓 × 200・照合 通過・床 A0 6.06・B0 7.31・C0 8.38・D0 7.74。**YATSUGATAKE M4**（2026-10-28、配線 N・ノイズ ON）: 4 窓 × 200・CRC 0・説明のない欠け 0・照合 通過・`g24cw` 全部通過・flags・health・miss 0。床の中央値 A0 6.47e3・B0 6.43e3・C0 6.32e3・D0 6.44e3（配線が N なので proj031 の N/S の値とは比べない）。陽性対照 `--src DCBA` で 4 窓とも NG。**YATSUGATAKE M5**（2026-10-28、配線 N、LMX PWR 3）: 4 窓 × 200・CRC 0・説明のない欠け 0・照合 通過・`g24cw` 全部通過・flags・health・miss 0、床の中央値 A0 6.48e3・B0 6.41e3・C0 6.33e3・D0 6.45e3、陽性対照 `--src DCBA` で 4 窓とも NG
