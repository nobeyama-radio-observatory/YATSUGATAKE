# F-2 — ADC → コアの遅れ（timebase.CAL[(3, 1)]）

- **前提**: 共通の前提。配線 P（1PPS を ADC_A〜D にも）。**specd を `SHUTDOWN confirm=1` で止め、`[s]pecd.py` で止まったことを確かめてから**、ボードの root で
- **手順**（proj031 R-5。道具は M5 から `g24f2.py` = 移植元の `widef2.py` の 2G-4 の版。`widef2.py` は SAM45-Wide の F-2。LMX は `--lmx-pwr` 既定 3）:

```bash
sudo -E $(which python3) g24f2.py --clkin 0 --ref 10 --adc 0,1,2,3 --out f2_a
# ADC のケーブルを A↔D・B↔C に入れ替える
sudo -E $(which python3) g24f2.py --clkin 0 --ref 10 --adc 0,1,2,3 --out f2_b
sudo -E $(which python3) g24f2.py --combine f2_a.f2.json f2_b.f2.json
```

- **合格**: 起動の照合（BIT_KIND 3・コア 4 個・RAW 1 本ずつ・PROJ 0x0031_0200）・(a) 4 ADC × 5 試行とも縁（最大 / σ ≧ 20）・**1 回の値は最多の山で読む**（2026-10-29 から）・2 回の差 ≦ 1 ビート、(p) 全部見えない。
  **最多の山で読む**: 1 回の 5 試行の T − スタンプを、隣との隙間が 0.5 ビートを越える所で山に分ける。最多の山が過半（≧ 3 / 5）で、その中の σ ≦ 0.4 ビート、ほかの山は最多の山から 1 ± 0.5 ビート（1PPS のスタンプがビートの境目に乗って 1 ビート跳ぶ回）。1 回の値は最多の山の平均。最多の山の外の試行の数（境目に乗った試行）は記録に書く（判定には使わない）。平均と σ で読まない理由: 1 ビート離れた 2 つの山を平均すると、どちらにも対応しない値と膨らんだ σ が出る（M5 の `f2_a`・`f2_b`。周期量・跳ぶ量に算術平均を使わない）
  **M が timebase.CAL[(3, 1)] の値（M = adc_to_core_ns − 71.5 = A 69.4・B 69.6・C 70.1・D 70.4 ns）と ±1 ビート（3.9 ns）**（Overlay の載せ直しごとの跳ね）。LMX の PWR を変えたら（M5 で 3 に）測り直して CAL を入れ直す
- **陽性対照**: (p)（1PPS を入れない側）で縁が見えない。最多の山の読みは `g24f2.py --selftest` に陽性対照（山が過半に届かない・山の間が 2 ビート・山の中が広い → どれも NG）
- **記録**: proj031 R-5 rev 2（2026-10-28、PWR 31）: M = 69.4〜70.4 ns、σ ≦ 0.13、2 回の差 ≦ 0.32 ビート。**YATSUGATAKE M5（2026-10-29、bit `e3521f51…`・PWR 3、配線 P）: 失敗（σ）・M は CAL どおり**。`f2_a2`（まっすぐ）A +17.93・B +17.88・C +17.93・D +17.93 ビート（σ 0.08〜0.13）、`f2_b`（A↔D・B↔C）+17.79・+17.93・+18.11・+18.09（σ 0.44・0.34・0.37・0.36、A が線 0.4 の外）。M = A 69.8・B 69.9・C 70.4・D 70.3 ns（CAL から +0.4・+0.3・+0.3・−0.1 ns）・2 回の差 0.05〜0.19 ビート → CAL 据え置き。最初の `f2_a`（まっすぐ）は σ A 0.41・B 0.40・C 0.42・D 0.34 で NG。σ の超えはどれも、縁のサンプルが止まったまま 5 試行のうち 1〜2 回スタンプが +1 ビート（1PPS のスタンプがビートの境目に乗る）。Overlay を載せ直すと抜ける（`f2_a2`）。(p) は 60 試行とも見えない（最大 / σ 3.0〜4.9）。σ の線の扱いは保留。制御 PC の `~/m2/2g4m5/f2/`。**読み直し（2026-10-29、最多の山）: 通過**。組（`f2_a2`・`f2_b`）: M = A 70.5・B 70.3・C 70.7・D 70.7 ns（CAL から +1.1・+0.7・+0.6・+0.3 ns）・2 回の差 0.22〜0.37 ビート・山の中の σ ≦ 0.13・境目に乗った試行 `f2_a2` 0・`f2_b` A 2・B 1・C 1・D 1 → CAL 据え置き。`f2_a` を組にすると C の 2 回の差 1.17 ビートで NG（`f2_a` の C は 3 対 2 で低い側の山が勝った。境目に乗った回は 1 回の値に 1 ビートの曖昧さが残る）。**2026-10-29 から 2G-4 では回さない**（ADR 0023。上の読み直しが 2G-4 の最後の F-2）。開発のボードの `time_cal.json`（同じ日に Wide の bit で `timecal.py`、M = A 69.6・B 71.2・C 69.7・D 69.7 ns、bound_ns 5）と、上の組の M（70.5・70.3・70.7・70.7 ns）の差は +0.9・−0.9・+1.0・+1.0 ns で bound の内（2G-4 の道が共通と同じことの実測の裏付け）
