# H-0 — 立ち上げ（2 窓の頭の欄・照合・床・2-for-1 の見張り）

- **前提**: 共通の前提。配線 N か N/S（どちらかを記録に書く。床の値は配線と入口の高さで変わる）。`ATT?` が 13 dB
- **手順**:

```bash
rm -f h0.s45
python3 specctl.py --host $B "SET A0.src=A B0.src=B shift=7 tint=0.04096 fmt=f32" "SEND ON" "START n=200"
python3 specrecv.py --host $B --out h0.s45 --seconds 15 --json h0.json
python3 g22cw.py h0.s45 --src AB
python3 specctl.py --host $B STATUS
```

- **合格**:
  - 受け: SPEC 400（2 窓 × 200）・CRC 0・説明のない欠け 0・照合 通過
  - `g22cw`: 全部通過（2 窓とも kind 1・nch 65536・core・src・nacc 1280・DUMP_T の進み 10,485,760・**2 窓の DUMP_T が揃う**）
  - **flags 0**（bit 7 の待ち行列のあふれ・pos_mis・2Y の飽和を含む）・health 0・sat 0
  - STATUS（STOP の後）: miss・kgap・drop・tp_lost・tp_bad 0・flags 0x000
  - 床（1 フレームあたりの中央値、窓ごと）: TP が proj034 R-2' と ±0.5 dB の内（A −31.4・B −31.35 dBFS 前後、ノイズ ON・ATT 13 dB）なら、床も proj034 R-2' の A0 3,196〜3,220・B0 3,175〜3,194 と ±0.7 dB（Overlay の載せ直しごとに動く幅。2G-4・2G-1-Fast の H-0 と同じ線）。TP が外れたら床は記録だけにする
- **陽性対照**: `g22cw.py h0.s45 --src CD`（期待の src を入れ替える）で NG（src の照合）。`--posctl` は CW の判定（`--sg-mhz`）にしか効かないので H-0 の陽性対照にならない（2G-4 の H-0 の注）
- **記録**: proj034 R-1（2026-10-29 22:43〜22:57 UTC、各 A0 A・B0 B × 200、`--fast` なし）: 4 回とも CRC 0・説明のない欠け 0・照合 通過・`g22cw` 全部通過・flags 0・sat 0、loop_max 20.8〜22.3 ms（proj025 も同じ）。このときは ATT が 100 dB のままで入力が来ず（TP −60 dBFS 前後）、床は R-2'（23:3x〜23:52 UTC、ATT 13 dB・ノイズ ON・TP A −31.39〜−31.42・B −31.34〜−31.37 dBFS）で取り直した: 床の中央値 A0 3,196〜3,220・B0 3,175〜3,194
- **YATSUGATAKE M4**（2026-10-31、配線 N・ATT 13 dB・ノイズ ON）: `--fast` なし・ありとも SPEC 400・CRC 0・説明のない欠け 0・照合 通過・`g22cw` 全部通過・flags 0・sat 0、STATUS の miss・kgap・drop・tp_lost・tp_bad 0。TP A −31.47・B −31.44（あり −31.49・−31.48）dBFS、床 A0 3.18e3・B0 3.15e3（あり 3.16e3・3.12e3）で線の内。陽性対照 `--src CD` で NG
