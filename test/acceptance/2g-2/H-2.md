# H-2 — ch → IF（直接の側と 2-for-1 の共役の側）

- **前提**: 共通の前提。配線 N/S・SG（基準 EXT）+9 dBm・**ATT 0 dB**（proj034 R-6 と同じ。終わったら 13 dB に戻して読み返す。戻すのは開発者に聞いてから）。**ノイズソースは道具で切る**（ADR 0024）: 取得の前に `python3 instr.py ns off`、4 点を取り終えたら `python3 instr.py ns on`。**SG を開いたまま取得する**（close が出力を OFF に戻す）。specd を起こし直してから
- **手順**: 4 点ごとに（2G-2 は ch c = round((4096 − f) / df)・df 31.25 kHz・送る番号 i = 65535 − c。行 = c mod 8192・銀行 = c div 8192、行 > 4096 が共役の側）

| f（MHz） | ch c | 送る i | 行・銀行 | 側 |
|---|---|---|---|---|
| 3000.25 | 35064 | 30471 | 2296・4 | 直接 |
| 2500.5 | 51056 | 14479 | 1904・6 | 直接 |
| 3396.5 | 22384 | 43151 | 6000・2 | **共役**（鎖の行 2192） |
| 2597.25 | 47960 | 17575 | 7000・5 | **共役**（鎖の行 1192） |

```bash
python3 instr.py ns off                                          # 4 点の前に 1 回（RFSOC_NS）
rm -f h2_<f>.s45
python3 specctl.py --host $B "SET A0.src=A B0.src=B shift=7 tint=0.04096 fmt=f32" "SEND ON" "START n=50"
python3 specrecv.py --host $B --out h2_<f>.s45 --seconds 10
python3 g22cw.py h2_<f>.s45 --src AB --sg-mhz <f>
python3 g22cw.py h2_<f>.s45 --src AB --sg-mhz <f> --posctl
python3 instr.py ns on                                           # 4 点を取り終えたら
```

- **合格**: 4 点 × 2 窓とも CW が見えている（ピーク / 中央値 ≧ `--min-db` 30 dB）・**ピークの送る番号 i が表の値と一致・軸と SG の差 ≦ df / 2**（proj034 は 0 Hz）・sat 0。
  **ピーク / 中央値 − TP（dBFS）が窓ごとに 4 点で ±0.5 dB の内**（直接の側と共役の側で利得が同じ。入口の高さは日と周波数で動くので、絶対のレベルでは判定しない）
- **陽性対照**: `--posctl`（軸の向きを逆）で 4 点 × 2 窓とも落ちる
- **記録**: proj034 R-6 の改め（2026-10-29 23:5x UTC、配線 N/S・ATT 0 dB・ノイズを `instr.noise_off()` で切った・SG +9 dBm 基準 EXT、各 A0 A・B0 B × 50）: 4 点 × 2 窓とも通過。送る番号 30471・14479・43151・17575 が期待と一致、軸と SG の差 0.0 Hz、**ピーク / 中央値 − TP A0 108.57〜108.68 dB（幅 0.11）・B0 108.53〜108.57 dB（幅 0.04）**、sat・miss・flags 0。陽性対照 `--posctl` で落ちた。SG OFF の床 TP −61.1〜−61.2 / −59.7〜−59.8 dBFS
