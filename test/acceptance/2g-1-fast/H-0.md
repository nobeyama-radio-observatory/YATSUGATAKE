# H-0 — 立ち上げ（頭の欄・照合・床・2-for-1 の見張り）

- **前提**: 共通の前提。配線 N か N/S（どちらかを記録に書く。床の値は配線と入口の高さで変わる）
- **手順**:

```bash
rm -f h0.s45
python3 specctl.py --host $B "SET src=A shift=7 tint=0.04096 fmt=f32" "SEND ON" "START n=200"
python3 specrecv.py --host $B --out h0.s45 --seconds 15 --json h0.json
python3 g21cw.py h0.s45 --src A
python3 specctl.py --host $B STATUS
```

- **合格**:
  - 受け: SPEC 200・CRC 0・説明のない欠け 0・照合 通過
  - `g21cw`: 全部通過（kind 1・nch 131072・src 0・nacc 640・DUMP_T の進み 10,485,760・DUMP_K 1 ずつ）
  - **flags 0**（bit 7 の待ち行列のあふれ・pos_mis・2Y の飽和を含む）・health 0・sat 0
  - STATUS（STOP の後）: miss・kgap・drop・tp_lost・tp_bad 0・flags 0x000
  - 床（1 フレームあたりの中央値）: TP が proj033 R-1 と ±0.5 dB の内（−31.3 dBFS 前後、ノイズ ON）なら、床も proj033 R-1 の 1,636〜1,644 と ±0.7 dB（Overlay の載せ直しごとに動く幅。2G-4 の H-0 と同じ線）。TP が外れたら床は記録だけにする
- **陽性対照**: `g21cw.py h0.s45 --src C`（期待の src を入れ替える）で NG（src の照合）。`--posctl` は CW の判定（`--sg-mhz`）にしか効かないので H-0 の陽性対照にならない（2G-4 の H-0 の注）
- **記録**: proj033 R-1（2026-10-28 22:15〜22:30 UTC、ノイズ ON・TP A −31.28〜−31.30 dBFS、`--fast` なし）: 2 回とも SPEC 200・CRC 0・説明のない欠け 0・照合 通過・`g21cw` 全部通過・health 0・flags 0x0・sat 0、STATUS の miss・kgap・drop・tp_lost・tp_bad 0、loop_max 12.8〜15.3 ms。床 1,642・1,636
- **YATSUGATAKE M6**（2026-10-31 02:51 UTC、配線 N/S・ノイズ ON・ATT 13 dB・src A、ボード `~/2g-1-fast-m6`・M5 の bit（usr 24150230）・`--prefault --fast --fast-ring`・tcal board）: **通過**。SPEC 200・CRC・欠け・説明のない欠け・kgap・tdev 0・照合 通過・`g21cw` 全部通過・health・flags・sat 0、STATUS の miss・drop・tp_lost・tp_bad 0、loop_max 6.41 ms。TP −31.45 dBFS（proj033 R-1 と −0.16 dB）・床 1.51e3（R-1 の 1,636 と −0.35 dB）。陽性対照（`--src C`）で NG
