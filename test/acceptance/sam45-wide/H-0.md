# H-0 — 雑音の 7 本（B 1・2・4 の混在で、レコードだけからスペクトルと IF の軸）

proj023 では ID の無かった判定（手順 4b の 3 回目・7 回目の「雑音の 7 本」）。ここで H-0 と名付けた。

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。配線 N（SG は出力 OFF）
- **手順**:

```bash
sudo -E $(which python3) wide.py --clkin 0 --ref 10 --mode A=1,B=2,C=4,D=1 --s0 A0=0,A1=12288,B0=0,B1=4096,D1=6000 --nacc 1250 --ndump 3 --out h0
```

- **合格**（測る前に決めた条件）:
  - 道具の判定が「結果: 全部通過」: 7 本（C は B 4 で流れ 1 が空）とも、レコードの頭の FFT_N・S0_CUR・NCH・PARAM が書いた値、SEQ が 1 から連続、FLAGS・SAT 0
  - IF の範囲が INTERFACE 2.1 の式 (S0 + i + (B − 1)/(2B))·fs / N のとおり（道具が出す流れごとの範囲）
- **陽性対照**: なし（ch → IF の取り違えは H-2 の陽性対照で見る）
