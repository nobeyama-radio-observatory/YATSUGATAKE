# P-8 — TP の線形性（L-1）・流れ / TP（L-2）と、Wide の TP の dBm 換算（tp_cal の (1, 1)）

Wide の TP は Fine と同じ作り（core_cmn は win_core の TP を番地・意味を変えずに写した）。Fine の (2, 3) を足したときと同じ形で、
**同じ日・同じ配線の Fine の bit と TP の dBFS − PM を比べ、差が小さければ K を測り直さずに tp_cal の `bits` に [1, 1] を足す**。

- **前提**: 共通の前提。specd（`--wide` なし）。**配線 N ＋ パワーメーター（2 分配器 B の ATT 20 dB の口）・プログラムアッテネータ**。比べの相手は SAM45-Fine の bit（bits.json の `proj021`、LOAD で切り替えて同じ日に）
- **手順**:

```bash
# Wide: 4 コアとも B 2 で 8 本（S0 0・4096 の 2 本で 2048〜4096 MHz を覆う）。B 4 は流れ 1 が空で、s45client の acquire が 8 本を待って止まる
python3 specctl.py --host $B "SET tint=0.04096 fmt=f32 all.b=2 all.shift=7"
python3 s45lin.py --host $B --pm $PM --att $ATT --lo 0 --hi 40 --step 2 --out lin_w
python3 s45lin.py --analyze lin_w.lin.jsonl
# Fine: 同じ配線・同じ日（Fine の P-8 と同じ SET）
python3 specctl.py --host $B "LOAD bit=proj021" "SET tint=0.04096 all.shift=9 A0.if=2176 A1.if=2432 B0.if=2688 B1.if=2944 C0.if=3200 C1.if=3456 D0.if=3712 D1.if=3968 A0.bw=256 A1.bw=256 B0.bw=256 B1.bw=256 C0.bw=256 C1.bw=256 D0.bw=256 D1.bw=256"
python3 s45lin.py --host $B --pm $PM --att $ATT --lo 0 --hi 40 --step 2 --out lin_f
python3 s45lin.py --analyze lin_f.lin.jsonl
```

- **合格**（測る前に決めた条件）:
  - L-1: TP が −18〜−28 dBFS になる段（今の配線で PATT 0〜10 dB）で、TP 4 本とも床を引いた値がパワーメーターに比例（残差 最大 ≦ 0.05 dB）
  - L-2: 流れ / TP（同じ ADC、流れの中央 90 % の和）がレベルによらず一定（±0.02 dB）。流れ 1（2048〜3072 MHz）の低い端は BPF の肩（2.1 GHz）にかかるが、レベルによらない形なので比は一定のはず
  - 飽和・振り切れ 0 の段だけを使う
  - **tp_cal の決め**: `s45lin --analyze` が出す `dBFS = PM + c`（ADC ごと）を Wide と Fine で比べ、**4 ADC とも差 ≦ 0.07 dB なら K を測り直さずに `tp_cal.json` の `bits` に [1, 1] を足す**。0.07 dB を越える ADC があれば、その ADC を `adc_port_cal`（PM を ADC の口で、2 回）で測り直してから足す
  - 足した後、specd を起こし直して `GET CAL` が (1, 1) で「使う」、STATUS の `tp_dbm` が数で出る
- **陽性対照**: 比べの Fine の bit が同じ配線で同じ `c` を出すこと自体が、配線に依る分と分光計の分を分ける対照
- **予言で書いておくこと**: `s45lin` の流れの量（`_abs_band`）は Fine の窓の尺度（4^SHIFT·4^(4−G)/2^31、偏り 2/3）で計算する。Wide の流れの絶対値はこの尺度では意味を持たないので、**流れ / TP の値そのものは記録だけ**にし、L-2（一定か）だけを判定に使う。`s45lin` が Wide の流れを読めることは PC の `specd --fake --wide` で確かめた（2026-10-23: `all.b=2` で 8 本の流れの量と TP 4 本が読めた。`all.b=4` では acquire が空の流れを待って時間切れ）
- **記録**: なし（Wide では新しい判定）。Fine の (2, 3) は YATSUGATAKE M6（2026-10-21、`~/m2/m6/lin_m6b`・`lin_m6b_p20`）で、proj020 との差 0.03〜0.05 dB で足した（`tp_cal.json` の `note_m6`）
