# H-4 — 運転中のモードの切り替え（ADC ごとに B を往復）

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。配線 N
- **手順**:

```bash
sudo -E $(which python3) wide.py --clkin 0 --ref 10 --switch 30 --nacc 100 --ndump 3 --out h4
```

- **合格**（測る前に決めた条件）:
  - 30 回の切り替えで NG 0 件: 毎回のレコードの頭（log2 NFFT・log2 B・S0）がその回に書いた設定と一致、RUN の中の SEQ が連続、DROP_CNT・REC_LATE が増えない
  - 流れの数が B 4 のコアを 1 本として数えた数（6 本か 7 本）と一致
- **陽性対照**: なし（期待は道具が書いた値で、DUT の読み返しは使わない。読み返しを期待にすると効かなかった設定でもつじつまが合う: proj023 手順 3a で見つけた穴）
