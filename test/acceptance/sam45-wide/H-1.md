# H-1 — 束ねた ch の応答（半 ch・−3 dB 幅・ENBW、B 1・2・4）

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。**配線 NS からノイズソースを OFF・PATT 0 dB**（SG 0 dBm、ADC で ≒ −35 dBFS。proj023 の合格回 h1b と同じ、CW / 床 62〜69 dB）。**改め（2026-10-23、YATSUGATAKE M6 の 2 回目の前）**: はじめ「ノイズは入ったまま（P_off を引いて消す）」と書いたのは書き起こしの誤り。P_off で消えるのは雑音の平均だけで、CW × 雑音の交差項 2·Re(C N*) の揺れは残り、相対の σ ≒ √(2 (N/C) / (Δν τ))。ノイズ ON・PATT 13 では C/N 15〜21 dB で σ ≒ 0.011 dB、9 点の max−min ≒ 0.03〜0.04 dB になり、揺れの線 0.02 dB を越える。合格の線は変えない。**SG を 300 s 温めてから掃引する**（`--warm 300`）
- **手順**:

```bash
sudo -E $(which python3) wideresp.py --clkin 0 --ref 10 --sg $SG --dbm 0 --warm 300 --out h1
sudo -E $(which python3) wideresp.py --analyze h1.h1.npz          # 判定だけやり直す
```
