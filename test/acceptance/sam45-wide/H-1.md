# H-1 — 束ねた ch の応答（半 ch・−3 dB 幅・ENBW、B 1・2・4）

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。配線 NS（ノイズは入ったまま、SG 0 dBm。雑音は SG を切った P_off を引いて消す）。**SG を 300 s 温めてから掃引する**（`--warm 300`）
- **手順**:

```bash
sudo -E $(which python3) wideresp.py --clkin 0 --ref 10 --sg $SG --dbm 0 --warm 300 --out h1
sudo -E $(which python3) wideresp.py --analyze h1.h1.npz          # 判定だけやり直す
```

- **合格**（測る前に決めた条件。値は `model/bin_resp.py` の模型）:
  - 4 本（A0 B 1・B0 B 2・C0 B 4・D0 B 1）とも、半 ch（u = ±0.5）の両側が模型 ±0.02 dB（B 1 −3.001、B 2・B 4 −3.010 dB）
  - −3 dB 幅が模型 ±0.005 ch（1.0008 / 1.0000 / 1.0000）、ENBW（|u| ≦ 5）が模型 ±0.5 %（1.0103 / 1.0081 / 1.0081）
  - 中心の繰り返し（掃引の間の 8 回）の揺れ ≦ 0.02 dB（B 1 は中心 8768.0 で見る）・SAT 0
- **陽性対照**: (B − 1)/(2B) を落とした軸では、B 2・4 の半 ch の両側が大きく食い違う（NG であるべき。道具が出す）
