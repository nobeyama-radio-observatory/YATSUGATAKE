# F-2 — ADC → コアの遅れ（timebase.CAL の (1, 1) の adc_to_core_ns）

RAW の流れの生サンプルで 1PPS の縁を見る（Fine の F-2 の (a) を Wide に移した `widef2.py`）。SLICE の D_S = 0（sim-wds）なので、ここで測った値がそのまま SLICE の utc_ns の adc_to_core になる。

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。**配線 P**（1PPS を PPS Clk と ADC_A〜D に分配、入口の LPF あり）。**LMX は PWR 3**（道具の既定）。ケーブルを入れ替えて 2 回測る
- **手順**:

```bash
sudo -E $(which python3) widef2.py --clkin 0 --ref 10 --adc 0,1,2,3 --out f2_a
# ADC のケーブルを A↔D・B↔C に入れ替えて
sudo -E $(which python3) widef2.py --clkin 0 --ref 10 --adc 0,1,2,3 --out f2_b
python3 widef2.py --combine f2_a.f2.json f2_b.f2.json      # 2 回の平均 M と判定
```

- **合格**（測る前に決めた条件）:
  - (a) 4 ADC × 5 試行とも縁が見える（最大 / σ ≧ 20）、1 回の中の σ ≦ 0.4 ビート、2 回の差 ≦ 1 ビート
  - M（2 回の平均、ns）が今の CAL（(1, 1): pps_det_ns 71.5 を引いた M で A 71.5・B 71.4・C 70.0・D 69.9 ns）から **±2.5 ns 以内**
  - **CAL の扱い**: LMX の強さ（31 → 3）を替えた後の最初の測りなので、M を (1, 1) の adc_to_core_ns（M ＋ 71.5）に入れ直す（±2.5 ns の内でも）。外れたら、外れた ADC と向きを記録してから入れ直す
- **陽性対照**: (p) 同じ手順で RAW のフレームを縁の 2 フレーム（1,024 ビート）前に置くと、5 試行とも縁が見えない（最大 / σ < 20）
- **記録**: **YATSUGATAKE M6（2026-10-26、bit `54b0dbea…`・PWR 3、配線 P・LPF あり、制御 PC の `~/m2/m6w/p/`）: 失敗（2 回の差 1.04〜1.27 ビート、線 1）**。`f2_a`（まっすぐ）A +17.34・B +17.30・C +17.25・D +17.27 ビート（σ 0.03〜0.08）、`f2_b`（A↔D・B↔C）+18.38・+18.57・+18.44・+18.48（σ 0.04〜0.05、A だけ 0.34: 5 試行のうち 1 回が縁のサンプル +0.13 ビートでスタンプ +1 ビート、差し引き −0.87）。4 ADC × 5 試行とも縁（最大 / σ 73〜228）、陽性対照 (p) は 40 試行とも見えない（最大 / σ 3.4〜5.2）。M（2 回の平均）A 69.8・B 70.1・C 69.7・D 69.8 ns（今の CAL から −1.7・−1.3・−0.3・−0.1 ns、±2.5 の内）。2 回目は 4 ADC がそろって +1.04〜+1.27 ビート（平均 +1.18）動き、ADC ごとの残りは −0.14〜+0.10 ビートで、入れ替えに合う A・D / B・C の逆向きの形は無い → ケーブルではなく Overlay ごとの 4 ADC 共通のずれ（proj021・026 の ≒ 0.9 ビートの件。今日はそれより大きい）。**扱いは保留・CAL は据え置き**（2026-10-26、実験者の判断。下の migration の塊 P）
  proj023（2026-10-21、配線 P・LPF あり、PWR 31、`f2_23a`・`f2_23b`）: M = 71.5・71.4・70.0・69.9 ns（2 回の差 0.03〜0.45 ビート）→ CAL (1, 1) の形 (b)。YATSUGATAKE「M5 の後」（2026-10-23、ケーブルの入れ替えなし、31 ⇄ 3 を各 2 回）: 縁の位置の差（3 − 31）A −0.03・B −0.62・C −0.56・D −0.51 ビート。B・C・D の ≒ 0.5 ビート（≒ 2 ns）は同じ PWR の 2 回の差と同じ程度で分けられず、ここで決める
