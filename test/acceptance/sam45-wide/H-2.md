# H-2 — ch → IF（B 1・2・4 で、SG の絶対周波数と束ねた ch の中心）

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。配線 NS（SG 0 dBm。**0 dBm より下は使わない**: E8257D は −10 dBm 以下で unleveled、−5 dBm でも CW が線形より 6 dB 低かった）
- **手順**（同じ ch 1234 の中心に SG を合わせ、B だけを変えて 3 回）:

```bash
sudo -E $(which python3) wide.py --clkin 0 --ref 10 --mode A=1 --tone-ch A0:1234 --dbm 0 --sg $SG --out h2_b1
sudo -E $(which python3) wide.py --clkin 0 --ref 10 --mode A=2 --tone-ch A0:1234 --dbm 0 --sg $SG --out h2_b2
sudo -E $(which python3) wide.py --clkin 0 --ref 10 --mode A=4 --tone-ch A0:1234 --dbm 0 --sg $SG --out h2_b4
```

- **合格**（測る前に決めた条件）:
  - 3 つの B とも、最大の ch が 1234、±1 ch の重心から見積もったずれが ±0.1 ch 以内
  - 中心の IF が INTERFACE 2.1 の式どおり: B 1 3941.7500・B 2 3787.4375・B 4 3478.8125 MHz
  - CW の高さ（ch の中央値に対して）: 中心 ≧ 10 dB・境目 ≧ 7 dB（CW が届いていることの確かめ。束ねた ch の雑音は B に比例して増えるので、B 4 でも満たす線）
- **陽性対照**: (B − 1)/(2B) を落とせば、B 2・4 で 0.25・0.375 ch ずれ、境目の比が 23・70 dB になる（道具が出す見積もり）。CW が届いていないとき（1 回目の −20 dBm）は CW の高さの判定で NG になる
